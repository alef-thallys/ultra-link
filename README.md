# PEX - Página UltraLink para Provedor de Internet

## Introdução
O PEX (Projeto de Extensão) tem como objetivo permitir a aplicação de conhecimentos teóricos em projetos reais, beneficiando empresas e comunidades. O UltraLink é um projeto que visa criar uma página web moderna e informativa para um provedor de internet, melhorando a comunicação com clientes e facilitando o acesso a informações sobre os serviços oferecidos.

## Necessidade do Projeto
Provedores de internet locais frequentemente enfrentam dificuldades na divulgação de seus serviços e atendimento ao cliente. Muitos ainda utilizam métodos tradicionais de contato, como telefone e atendimento presencial, o que pode gerar filas e demora no suporte. A criação de uma página web ajudará a centralizar informações e oferecer uma experiência mais eficiente para os usuários.

## Objetivos do Projeto

### Objetivo Geral
Desenvolver uma página web responsiva e intuitiva para o provedor de internet UltraLink, facilitando o acesso a informações e melhorando a experiência do usuário.

### Objetivos Específicos
- Criar uma página que apresente os planos de internet disponíveis.
- Disponibilizar um canal para solicitação de novos planos.
- Garantir que a página seja responsiva e acessível em dispositivos móveis e desktops.

## Justificativa
A digitalização dos serviços de provedores de internet é essencial para oferecer um melhor suporte aos clientes e aumentar a visibilidade da empresa. Com uma página bem estruturada, os usuários poderão encontrar informações sobre planos e entrar em contato com facilidade, reduzindo a necessidade de atendimento presencial ou via telefone.

## Metodologia

1. **Análise de Necessidades**: Levantamento dos principais pontos que devem estar na página.
2. **Escolha da Tecnologia**: Definição das ferramentas para o desenvolvimento.
3. **Desenvolvimento da Página**: Implementação do design e das funcionalidades.
4. **Ajustes**: Verificação de responsividade e experiência do usuário.
5. **Publicação e Monitoramento**: Lançamento da página e acompanhamento do funcionamento.

## Tecnologias Utilizadas
- **Front-end**: HTML, CSS (Tailwind CSS) e JavaScript
- **Banco de Dados**: Não aplicável

## Instalação

Para rodar o projeto localmente, siga os passos abaixo:

1. Clone este repositório para o seu computador:

    ```bash
    git clone https://github.com/alef-thallys/ultra-link.git
    ```

2. Navegue até o diretório do projeto:

    ```bash
    cd ultra-link
    ```

3. **Instale as dependências do projeto com o npm:**

    Execute o comando abaixo para instalar todas as dependências necessárias:

    ```bash
    npm install
    ```

4. **Execute o projeto localmente:**

    Para rodar o projeto, use o comando:

    ```bash
    npm run dev
    ```
    
Se você deseja fazer alterações no código, é necessário ter um editor de texto como o **VS Code** ou outro de sua escolha.
